Technology Stack & Cách Chạy

Học máy

  • PyTorch + torchvision (ResNet ImageNet weights)
  • AMP FP16, DataParallel, channels_last
  • OpenCV — affine, augmentation uint8, JPEG
  • pycocotools — COCO OKS-AP
  • NumPy, matplotlib

Server & Web

  • FastAPI + uvicorn — REST, WebSocket, Swagger, static
  • Three.js (vendor, không cần CDN)
  • JavaScript ES modules, Canvas 2D, getUserMedia

Hạ tầng

  • Kaggle Notebook — 2× Tesla T4, sinh từ skypose_train_kaggle.py
  • Laptop RTX A2000 4 GB — dev, chạy game
  • Git + GitHub (SGU-ML25/PatternRecognition)
